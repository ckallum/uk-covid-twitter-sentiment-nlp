# COVID-19 Sentiment Analysis in the UK

A **fully static** dashboard that visualizes UK Twitter sentiment towards COVID-19 and lockdown from March 2020 to March 2021. No server required — all data is pre-computed into JSON files and rendered client-side with Plotly.js.

## Features

- Interactive timeline with 371 days of data — play button animates through the pandemic
- County-level choropleth map of sentiment across the UK
- Four sentiment analysis techniques: Vader, TextBlob, LSTM, Naive Bayes
- Daily COVID statistics (deaths, cases, R-number) synced to the date slider
- Top hashtags, emojis, and news headlines per day
- 7-day moving averages for sentiment and COVID stats
- Correlation analysis between sentiment, tweet volume, cases, and deaths
- Wordclouds for top keywords and emojis

## Running Locally

The site is fully static but must be served over HTTP (not `file://`) because it loads JSON data via `fetch()`.

```bash
# From the project root
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## Regenerating Data

The pre-computed JSON files in `data/json/` are already committed. To regenerate them from the source CSVs (e.g. after updating data):

```bash
python3 -m venv venv
source venv/bin/activate
pip install pandas numpy
python3 build.py
```

The build script reads all CSVs in `data/`, computes moving averages, aggregates tweet-level sentiment counts, and emits optimized JSON to `data/json/` (~9.5 MB total).

## Deploying

Deploy any way static files can be served:

- **GitHub Pages** — push to `main`, enable Pages in settings
- **Netlify / Vercel** — drop the repo, no build command needed (point to root)
- **Any static host / CDN** — upload the repo contents

No backend, no serverless functions, no build step required at deploy time.

## Data Sources

- **Twitter data**: Collected with [SNScrape](https://github.com/JustAnotherArchivist/snscrape)
- **COVID statistics**: [Public Health England](https://coronavirus.data.gov.uk/)
- **News events**: [Guardian News API](https://open-platform.theguardian.com/)
